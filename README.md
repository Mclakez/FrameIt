# FrameIt — Batch Image Branding Tool

FrameIt is a full-stack web app that lets users upload a batch of photos, apply a branded overlay once, and download all images as a ZIP file. Built for event photographers, social media managers, and anyone who needs to brand images at scale.

🔗 **Live Demo:** [frame-it-wine.vercel.app](https://frame-it-wine.vercel.app)

---

## Features

- Upload multiple images and apply a logo overlay in one step
- Canvas-based image processing with adjustable overlay positioning
- Batch download as a ZIP file
- JWT authentication with HttpOnly cookies
- Google OAuth sign-in via Passport.js
- Logo storage and management via Cloudinary
- Fully responsive across mobile and desktop

---

## Tech Stack

**Frontend**
React · TypeScript · Tailwind CSS · Canvas API · JSZip

**Backend**
Node.js · Express · MongoDB Atlas · Cloudinary · Passport.js · JWT

**Deployment**
Vercel (frontend) · Render (backend) · MongoDB Atlas (database)
